Scope and method
----------------
Three fresh serial processes per executable per input. Execution order is
before/after, after/before, before/after. No untimed warmup. Report medians.
Timing includes process startup, source parsing, inference, elaboration,
independent verification, and captured xMLF output. It excludes building
the compiler and running the compiled program. This compares two versions
of emlf, not emlf with GHC native code generation.

All 16 examples produced byte-identical xMLF in all six runs. Each emitted
output was also parsed and checked with --check outside the timed region.

Changes
-------
- Share completed kind results across one validation pass. This same walk
  detects missing structural nodes and cycles.
- Traverse the binding tree once and use DFS intervals for ancestry tests.
  Missing binders, extra roots, and disconnected binding cycles still fail.
- Stop structural containment searches at the requested descendant.
- Use independently checked Inst-Refl for alpha-equivalent instance types.
  Other edges retain final-presolution expansion and identity-based proofs.
- Skip an empty frontier unification; the following unification still
  validates the expansion before merging anything.

An initial -fprof-auto profile attributed about 66% of measured time to
graph validation, including 566,982,192 binding-path visits. Profiling was
used to locate bottlenecks; the table above uses ordinary executables.

Reproduction
------------
Preserve the earlier executable before rebuilding the compiler, then use:
cabal bench compiler-bench -j1 \
  --benchmark-options='compare-revisions --before dist-newstyle/compiler-performance/emlf-before --runs 3 --output dist-newstyle/benchmarks/comparison.json'

Cabal supplies the newly built compiler, and the driver selects all examples
when no source paths are given. Match the source/prelude configuration to the
saved compiler when reproducing this historical comparison.

The local comparison.json contains all raw samples, input and binary hashes,
output hashes, and independently checked types. It is a build artifact;
the benchmark script and this summary are included in the source package.
