Scope and method
----------------
eMLF compiles examples/snake.emlf to verified xMLF, with the implicit
standard prelude. GHC compiles examples/SnakeBaseline.hs to a linked native
executable with -O2 -Wall -Werror -fforce-recomp -main-is SnakeBaseline.
These are different output formats; this comparison measures the requested
compilation workflows, not equivalent native backends or game execution.

Each sample starts a fresh process. GHC recompiles and links on every run;
no successful compilation is reused. Order alternates eMLF/GHC, GHC/eMLF.
There is no untimed compilation warmup. Timing includes process startup,
source reading and captured compiler output, and excludes building emlf.
The script rejects any paired ratio above 5, not just a median above 5.

Implementation
--------------
- Dense source graphs use temporary ST arrays for graph analyses. Public
  graphs with sparse identities retain the map-based implementation, so
  scratch space remains proportional to the number of nodes.
- Number the binding tree once; fuse structural cycle, kind, containment,
  and domination checks in one memoized traversal. Check every structural
  edge's scope even when its child's kind is already cached.
- Rebind uses a memoized dependency DFS and cached depths for binding LCAs.
  Its dependencies include all reverse structural edges, which also catches
  structural cycles created by unification. The redundant separate
  topological traversal is gone; the occurs check remains enforced.
- Mark the union of grafted descendants once, sharing work across instances.
- Permission checks continue to refer to original identities and their
  raised binders. Evaluate permission tables only for relevant changes.
- Use strict graph fields and reuse unchanged nodes during canonicalization
  and rebinding, reducing allocation and retaining sharing.
- Use -O2 and a 32 MiB CLI allocation area to reduce garbage collection.
  The latter is a nursery size, not a fixed maximum heap, and is overridable
  with RTS options.

Graph validation still runs before and after every unification. Independent
target typing, computation checking, inferred-type agreement, and source
erasure checks remain enabled. No Snake-specific compiler path was added.
Neither game source was changed for these measurements.

Reproduction
------------

  --emlf "$(cabal list-bin exe:emlf)" \
  --runs 5 --output dist-newstyle/compiler-target/ghc-comparison.json

To require byte-identical output against a saved earlier compilation, add
--reference-xmlf /path/to/snake-before.xmlf. The script uses only Python's
standard library, saves raw samples and fingerprints in JSON, persists the
checked xMLF beside that report, and exits unsuccessfully if any pair misses
the limit. Timings are machine- and load-dependent.
