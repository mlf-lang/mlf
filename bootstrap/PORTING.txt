Native MLF compiler maintenance contract

The compiler is implemented in ordinary .emlf source. Bootstrap from a native
MLF release; the Haskell compiler and old Haskell/Python harnesses are retired.
No subprocess delegation to an older compiler, embedded seed binary, or cached
answers is allowed in the compiler. Every generation independently parses,
infers, elaborates, checks, interprets, and emits LLVM.

Use the root MLF package manager to run all six groups, including the fresh
self-host fixed point, frozen parity corpus, independent reference algorithms,
and interpreter/LLVM matrices in both runtime layouts. A self-rebuild alone is
not sufficient validation. See README.md and ../tests/README.md.

Source uses the CURRENT supported .emlf syntax: modules, ordinary ADTs,
explicit forall signatures, function equations, layout, do, if and fixed
operators. No Haskell lists/tuples/records/type synonyms/guards/where.
Every recursively connected top-level function needs an explicit signature.
Use shared types from Bootstrap.Types and containers from Bootstrap.Std,
Bootstrap.Map, Bootstrap.Set, Bootstrap.IntMap, Bootstrap.IntSet.

Foundation conventions:
  List a = Nil | Cons a (List a)
  Pair a b = Pair a b; Triple a b c = Triple a b c
  Maybe a = Nothing | Just a; Either e a = Left e | Right a
  Map k v and Set a: persistent ordered trees, comparator returns Int.
  Source types/expressions/annotations use SType, SExpr, SAnnotation and
  constructor prefixes S (SVar, SLam, SCon, etc.). Target types and terms use
  XType, XTerm, XComputation, XErased with constructor prefixes X.
  Graph types use Graph, Node, GTag and G-prefixed tag constructors.
  Shared Kind = Star | KArrow Kind Kind; Flag = Flexible | Rigid.
  Types.emlf owns all compiler AST and graph datatypes to avoid module cycles.
  Owners must publish exact exported signatures and coordinate mismatches.

Host IO primitives and allocator profiles are specified in RUNTIME.txt.
Independent golden types and benchmark baselines must not be rewritten from
the compiler under test.
