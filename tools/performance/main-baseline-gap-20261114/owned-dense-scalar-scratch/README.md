# Owned dense scalar scratch: isolated GHC experiment

Current engineering decision: **STOP this variant after the distinct Async workload.** Finite Solver integration passed, but Async time pairs were mixed and both peak-RSS ratios rose by 23.3010%. The two-pair wall geometric ratio was 1.02130418, about 2.13% more time, not a stable regression estimate. Every prespecified continuation criterion failed. Do not promote, port or add samples to rescue this variant; the favorable Foundation screen below remains historical evidence, not a general speedup.

## Distinct real Async checking service
The same ordinary A/C binaries checked five unchanged Async modules and their three Foundation dependencies through a tiny Bool Root. The nine-source static closure totals 105,297 bytes; --type does not run Task/process actions. A qualification and C qualification both passed before fixed A1/C1/C2/A2. All six outputs were exact Bool plus newline, with empty stderr; qualification calls were measured and budgeted but excluded from performance aggregates. No dynamic loaded-module observer was added.

Target wall times were 12.417494535 / 13.923223465 / 12.591391633 / 13.535345010 seconds. Paired C/A wall ratios were 1.1212586747 and 0.9302601170: one slower and one faster. Wall geometric C/A = 1.0213041789; CPU geometric C/A = 1.0215858084. Both A peak-RSS observations were 355,744 KiB and both C observations 438,636 KiB, ratio 1.2330102546. These are only two descriptive pairs. All six continuation thresholds failed. Raw sanitized measurements, independent Decimal arithmetic and prespecified thresholds are in results/async-type-screen.json. Full private evidence is retained separately.

This is not a semantic failure and does not erase the Foundation signal. It stops unrestricted adoption of this GHC-only version; storage changes and helper visibility/fusion remain confounded. No extra sampling, native fixed-point run, main change or merge follows this archive.
