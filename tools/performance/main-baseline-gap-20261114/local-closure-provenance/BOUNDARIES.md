# Interpretation and qualification boundaries

## Finite gate

One O2 fixture passed 14 records and the exact 73-file working-output contract. This is not an all-input equivalence proof. Only `ordinary` and `fresh-solve` compare full original/new Solver results, including physical maps, links, parent/child indexes and scope structures, against hand-constructed expected graph values. These comparisons are value-level, not heap-identity or residency claims.

The remaining records cover component discovery, direct projection metadata, literal errors and typed synchronous poison, and synthetic observer eligibility. The 129-node positive metadata record uses a raw identity action with unbound bottom nodes; it is not a valid `G.unify` graph. Inputs of 128 and 2,049 nodes bypass poisoned metadata. Inputs of 129 and 2,048 nodes demand it, throw the expected typed Probe and append no accepted row. Left bypasses graph, equations and metadata.

The finite capture has six accepted rows. Only the 129-node synthetic positive row has numeric metadata. The ordinary/fresh captured rows have four/three nodes and therefore NA metadata. An earlier source-design sentence about an ordinary equation-unique count of two describes the direct projection metadata, not the selected capture row.

There is no positive finite scope-added, first-binding-child or first-fresh-external discovery case. Fresh node 3 is deleted and aliased to node 1 in the tested restoration; publication of a surviving fresh node is not covered. Hidden-stub testing compares the projection tuple, not its downstream restoration. Original helper functions are retained as oracles in the same module. The finite fixture invokes diagnostic siblings directly; the actual CLI run separately exercises the changed routing sites.

## Real diagnostic

One fresh GHC O2 96-home producer and one Root + Foundation `--type` target passed the original exact `Bool\n` stdout, empty stderr and exit-zero contract. Five supervised children are two C compiles, one GHC build, one bounded dependency inspection and the target. There are zero performance samples, no A/B timings and no automatic retry. The runs do not execute the user's compiled application or MLF native-backend/fixed-point qualification.

The capture is diagnostic, not observationally transparent. It forces full successful inputs after the local action reaches `Either` WHNF, does additional traversal/set work, retains numeric rows, and changes demand, allocation, residency and elapsed time. It does not force the successful result graph to normal form. A syntactically single observation wrapper is not proof of no lazy re-entry.

Only successful local input sizes 129..2048 receive metadata; other Right and all Left rows are NA. This is a selector by encoded node count, not by max node ID. Six origin counters are updated during discovery; the size selector avoids demanding later metadata outside the range, not all instrumentation overhead outside the range.

Connected + added scopes + fresh + hidden stubs is a partition of each selected local input's node occurrences. Across events, the same logical node can be counted repeatedly. First-discovery buckets depend on traversal order and are not all-edge incidence, unique causes, necessity certificates or safe deletion opportunities. In particular, a zero first-fresh-external or first-binding-child bucket does not prove that the corresponding edges or algorithms are absent. The nonzero external seed set and earlier discovery can coexist.

Equation/fresh/external direct set cardinalities overlap. Their union/intersection arithmetic is checked separately; adding them to the node partition double-counts. Scalar conservation is not proof of set identity or generated-pipeline semantics.

## Intervals and fingerprints

`action_whnf_ns` spans the original local action until the outer Either constructor is available. Input-thunk re-entry can overlap intervals. The sum is a reported interval sum, not exclusive CPU, a disjoint CLI phase or total Solver time. The fingerprint interval can include GC and scheduling within that interval; it excludes separately executed metadata formation, later bookkeeping and final TSV output. Neither interval can be subtracted from outer wall time to claim net overhead. Outer target elapsed time is budget telemetry, not a benchmark. No target CPU or peak-RSS measurement was added.

First-seven-field equality with the earlier v4 run preserves the ordered site/success/size/fingerprint transcript, not raw graph equality. The two Word64 fingerprints are exact numeric observations, not collision-free keys. No cross-run timing join or new cache conclusion is made.

## Scope

GHC-host diagnostic only; native work is paused. Main and the PR were not changed. Existing generic full-graph caching, scope-owner and other stopped optimization directions remain stopped. This package supports source review and bounded data interpretation, not a production patch or a promise of performance. No binary, private filesystem path, Library identity, session/tool identifier or real input graph is included.

## Current optimization decision

The follow-on read-only change-set localization study found no sufficiently maintained dependency/invalidator certificate for safely restricting validation or rebinding. Connected context is not automatically unchanged reusable context. Existing memoization and changed-binding permission reuse already apply; aliased children, binder/permission dependencies, graft reachability, kinds and cycle checks can invalidate work beyond equation IDs. Current evidence therefore supports **NO_GO for a production localization shortcut**, not a new optimization or deletion of checks. No additional experiment is implied.
