## Reproduced failure

The preserved failed CPU diagnostic's 3,294-file inventory was generated by
sorting `pathlib.Path` values. The disabled completion controller instead
compared it with sorted strings. These orderings differ when a directory and
a dotted filename share a stem: `Graph/IndexStore.p_hi` precedes `Graph.p_hi`
in Path order, but not in string order. The original complete, byte-authenticated
inventory is unique and Path-sorted; the old predicate rejects it unchanged.

The patch changes only `sorted(names)` to `sorted(names, key=Path)`.
The frozen inventory is not rewritten or sorted on the expected side. The
directory check stays string-sorted, matching its separate producer. Original
row objects, sizes, hashes, file-type/alias checks, old-scope verification,
budgets and execution gates are unchanged.
