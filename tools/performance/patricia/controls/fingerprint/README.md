# Int64 fingerprint controls

These are the directly compiled control programs for `patricia-fingerprint`.
`Oracle.hs` supplies independent literal arithmetic and demand behavior;
`Probe.hs` calls the current public primitives; `Tests.hs` compares the two using
the retained finite inputs, exception ordering and bounded divergence checks.
The runner also checks optimized Core and recompiles current `Bootstrap.Separate`
against a copy of the selected producer's objects.

The files were materialized once from the established Int64 preparation at
`171717ad5bd025ee977d4ca9fd8f93abcbc68612`. The previous preparation changed
host-side `Integer` annotations to `Int64`, kept all literal input rows, changed
one noncanonical divergence seed from the wrapped `2^1024` to `-1`, and added
30 full-width signed pairs. `Tests.hs` retains its original final module name.
All three files match that preparation byte for byte. The oversized historical
inputs now wrap and may coincide; these controls do not claim arbitrary-precision
semantics.

`expectations.json` retains the independently authored stdout and stderr. It was
not generated by running the candidate compiler. Future control changes should
edit these ordinary tests and their expected observations directly. No historical
checkout, source transformer, reverse diff or growing source-hash chain is needed
to execute them. Each run records and rechecks its actual inputs and producer.
